Guide de Configuration (A à Z)

1. Configuration de Prowlarr ⚙️

Pour éviter que Prowlarr n'écrase vos modifications personnalisées lors de la synchronisation de ses indexeurs vers Radarr/Sonarr, vous devez modifier son niveau de synchronisation :

  • Ouvrez l'interface de Prowlarr.
  • Allez dans Paramètres > Applications.
  • Cliquez sur votre application Radarr (ou Sonarr).
  • Changez le Niveau de synchronisation en Ajouter et supprimer uniquement (Add and Remove Only).
  • Sauvegardez. Prowlarr ajoutera les nouveaux indexeurs mais laissera vos modifications intactes !

2. Trouver les URLs dans Radarr/Sonarr 🔍

Prowlarr a créé des indexeurs dans votre Radarr (ex: NekoBT, NorTorrent). Vous allez devoir modifier leur URL pour les faire passer par ce proxy (Animarr).

  • Allez dans Radarr, puis Paramètres > Indexeurs.
  • Ouvrez un indexeur créé par Prowlarr (ex: nekoBT (Prowlarr)).
  • Regardez l'URL actuelle. Elle devrait ressembler à http://127.0.0.1:26234/prowlarr/1 ou /2, etc.
  • Prenez note du numéro final de l'URL (ex: le /1).

3. Configurer Animarr dans Radarr/Sonarr 🚀

C'est ici que la magie opère. Vous allez remplacer l'URL de Prowlarr par celle d'Animarr :

  • L'URL de base d'Animarr correspond à l'adresse (ou tunnel) sur laquelle vous vous trouvez actuellement (ex: http://localhost:5000 ou votre tunnel public).
  • Dans Radarr, remplacez l'URL de votre indexeur par l'URL d'Animarr en y ajoutant le numéro de l'indexeur.
  • Exemple : Si l'ancienne URL était http://127.0.0.1:26234/prowlarr/1, et qu'Animarr est sur http://127.0.0.1:5000, la nouvelle URL devient http://127.0.0.1:5000/1.
  • Ne touchez pas à la clé API dans Radarr. Gardez celle qui y est déjà.
  • Cliquez sur Tester. Vous devriez obtenir une coche verte !
  • Cliquez sur Sauvegarder. Répétez l'opération pour vos autres indexeurs en changeant juste le numéro (/2, /3, etc.).

💡 Comment ça marche en coulisses ?

Quand Radarr lance une recherche, il interroge Animarr avec l'URL /1/api. Animarr capte la requête, corrige les titres via les APIs externes, puis transfère silencieusement la recherche corrigée à Prowlarr en appelant [URL_PROWLARR_CONFIGUREE_DANS_ANIMARR]/1/api. Les résultats sont ensuite nettoyés et renvoyés à Radarr !
